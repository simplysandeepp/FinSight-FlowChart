What You Have Right Now

🧠 Multi-Agent AI Core
  • 4 specialized agents running in parallel via asyncio.gather()
  • Transcript NLP — Groq LLaMA 3.3-70b
  • Financial Model — XGBoost quantile regression (6 models)
  • News & Macro — Groq + Gemini fallback
  • Competitor Agent — peer benchmarking via LLM
  • CIO Ensembler — final Buy/Hold/Sell signal
  • 10s timeout per agent, graceful degradation
⚙️ Backend Infrastructure
  • FastAPI with Pydantic validation
  • asyncio parallel orchestration
  • Groq key rotation (multiple keys, round-robin on 429)
  • Gemini fallback when all Groq keys fail
  • SQLite audit trail (aiosqlite async writes)
  • CORS configured for localhost:5173
  • Docker support via Dockerfile
🖥️ Frontend Dashboard
  • React + Vite, Tailwind CSS
  • Revenue confidence interval chart (Recharts)
  • KPI cards: signal, confidence, latency
  • Transcript driver highlights
  • Signal attribution bars per agent
  • Peer benchmarking table
  • Audit trail page, Active Signals page
⚠️ Current Gaps (Honest Assessment): All financial data is synthetic (fake 40 companies). Alpha Vantage only gives 25 API calls/day. No user accounts — everyone shares the same app. No plain English mode — jargon everywhere. Can only run on localhost, not deployed live. No way for users to save or export their reports.
Architecture

How It Works Right Now

PHASE 0 — Offline Training Pipeline (run once before starting server)
generator.py
Synthetic Data Generator
  • Creates 40 fake companies × 20 quarters = 800 rows
  • GBM or AR(1) revenue simulation
  • Bull/Neutral/Bear scenarios
  • 10 transcript templates with sentiment
→ out/synthetic_financials.csv
→ out/sample_transcripts.jsonl
feature_store.py
Feature Engineering
  • Lag features: revenue 1Q/2Q/4Q, EBITDA 1Q
  • Rolling 4Q mean & std
  • YoY & QoQ growth rates
  • Temporal split: 70/15/15 by date
← synthetic_financials.csv
→ out/features_v1.pkl
→ out/feature_manifest.json
financial_model.py train()
XGBoost Training
  • 2 targets: revenue + EBITDA
  • 3 quantiles: α = 0.05, 0.50, 0.95
  • = 6 XGBoost models total
  • Objective: reg:quantileerror
← features_v1.pkl (train+val)
→ out/financial_model.pkl
PHASE 1 — User Request Entry
React Frontend → FastAPI
  • User types ticker (AAPL, COMP_007) + selects date
  • POST /api/predict → FastAPI validates with Pydantic
  • Auto-generates UUID request_id
  • Calls orchestrate() async function
→ { company_id, as_of_date, request_id }
PHASE 2 — Orchestrator Routing
orchestrate.py — Data Decision
  • If real ticker → yfinance (8 quarters quarterly financials)
  • If COMP_XXX → load from features_v1.pkl (synthetic)
  • Fetch transcript (synthetic .jsonl or placeholder text)
  • Fetch peer companies via PEER_MAP[ticker]
  • Dispatch all 4 agents via asyncio.gather()
  • Minimum 2 agents must succeed — else 503 error
PHASE 3 — Parallel Agent Execution
⚡ asyncio.gather() — All 4 agents fire simultaneously
Agent 1
Transcript NLP
🦙 Groq LLaMA 3.3 ✦ Gemini fallback
  • Extracts 5 key driver sentences
  • Sentiment score [-1 to +1]
  • Management confidence [0 to 1]
  • All numeric facts (revenue, EBITDA)
  • Flags optimistic language + bad numbers
OUT: drivers, sentiment, topics, confidence
FAIL: confidence=0.5, empty lists
Agent 2
Financial Model
🌲 XGBoost Only
  • Loads 6 XGBoost models from .pkl
  • Predicts Revenue p05 / p50 / p95
  • Predicts EBITDA p05 / p50 / p95
  • Enforces: p05 ≤ p50 ≤ p95
  • Confidence = 1 − (p95−p05)/(2×p50)
  • Returns top 5 feature importances
OUT: revenue forecast, ebitda forecast, confidence
Agent 3
News & Macro
🦙 Groq LLaMA 3.3 ✦ Gemini fallback
  • Analyzes news headlines + macro data
  • Returns macro sentiment [-1 to +1]
  • Returns sector outlook string
  • Returns list of risk factors
  • Currently: Alpha Vantage (only 25/day!)
OUT: macro_sentiment, sector_outlook, risk_factors
UPGRADE: Replace Alpha Vantage with NewsAPI + FRED
Agent 4
Competitor Intel
🦙 Groq LLaMA 3.3 ✦ Gemini fallback
  • Benchmarks vs peer companies
  • Revenue delta & margin delta per peer
  • Relative position score [-1 to +1]
  • Currently: yfinance peer data only
  • No peers for synthetic COMP_XXX
OUT: relative_position, peer_benchmarks[]
UPGRADE: Replace with Finnhub peer data
All 4 agent outputs merge into CIO Ensembler
PHASE 4 — Final Signal
CIO Ensembler Agent — Chief Investment Officer
Input
  • All 4 agent outputs as dict
  • Only successful agents included
  • Degraded agents logged separately
LLM Synthesis
  • "You are a chief investment officer"
  • Returns: action (buy/hold/sell/monitor)
  • Returns: rationale, explanations list
  • Returns: human_review_required bool
Confidence Calc
  • Geometric mean of all agent confidences
  • Penalty: × 0.9^(num_degraded)
  • Final confidence clamped [0, 1]
PHASE 5 — Response
Final JSON Payload
  • request_id, trace_id, model_version
  • status: "success" or "partial"
  • latency_ms, data_source
  • result (full EnsemblerOutput)
  • explainability: confidence per agent
  • agents_called[], degraded_agents[]
PHASE 5 — Persistence
audit_trail.py → SQLite
  • aiosqlite — async writes, non-blocking
  • Table: requests (request_id PK)
  • Stores all agent call history
  • Stores final output JSON
  • ⚠️ Upgrade to MongoDB for multi-user
PHASE 5 — Rendering
React Dashboard Display
  • KPI cards: signal, confidence, latency
  • Revenue CI chart (Recharts bar chart)
  • EBITDA forecast card
  • Transcript driver highlights
  • Signal attribution bars per agent
  • Data source badge (live vs synthetic)
Upgrades Required

What Needs to Change & Why

What ❌ Current (Problem) ✅ Upgrade To (Solution)
Financial Data Source Synthetic fake data — 40 fake companies. Zero credibility in demos. Finnhub API — real companies, free tier, 60 calls/min. Works for AAPL, NVDA, TSLA, any ticker.
Macro Data Hardcoded or missing. GDP = 0.02, interest_rate = 0.05 always same values. FRED API (Federal Reserve) — official GDP, inflation, interest rate, unemployment. Unlimited, free forever.
News Headlines Alpha Vantage — only 25 requests per day. Breaks after a few demos. NewsAPI free tier — 100 req/day. Real company news. Plus Finnhub news endpoint as backup.
User Data Support No way for user to upload their own company data. Only predefined tickers work. CSV upload — user uploads their own quarterly data. Backend parses it, runs full analysis on it.
ML Training Data XGBoost trained on synthetic fake data. Model has never seen real financial patterns. Collect real Finnhub data for 25+ real companies, retrain XGBoost on real historical financials.
LLM Output Language Everything in financial jargon. Faculty/students who don't know finance can't understand it. Two-section prompt: Expert Analysis + Plain English Summary. Simple verdict like "Good time to invest."
Dashboard Modes One dashboard for all users. Way too complex for normal investors. Too simple for startups. Mode toggle: Normal Investor view (plain language) vs Startup/Business view (full financial detail).
User Accounts No login. No saved history. Everyone shares same app, same audit trail. Firebase Auth — free, Google OAuth + email. Every user gets isolated data in MongoDB.
Report Storage SQLite — good for single user, not for multi-user deployment. No per-user isolation. MongoDB Atlas — free 512MB, per-user reports tagged by Firebase uid. Motor async driver.
Deployment Only runs on localhost. Can't share live link. Faculty has to run it locally themselves. Render.com (backend) + Vercel (frontend) — both free. Share one live URL with anyone.
Get These Free API Keys First — Takes 5 Minutes
Finnhub API
Real company financials, peer data, company profiles, news. Free tier: 60 API calls per minute. Sign up at finnhub.io — takes 2 minutes. Replaces both yfinance AND synthetic data.
FINNHUB_API_KEY=pk_xxx
FRED API (Federal Reserve)
Official US macroeconomic data — GDP growth, CPI inflation, Fed funds rate, unemployment, S&P 500. Completely free, no rate limits. Sign up at fred.stlouisfed.org/docs/api
FRED_API_KEY=xxx
NewsAPI
Real news headlines for any company. Free tier: 100 requests per day — plenty for demos. Sign up at newsapi.org. Replaces Alpha Vantage which only allowed 25/day.
NEWS_API_KEY=xxx

Every File You Need to Create or Modify

Backend — New Files to Create
backend/data_sources/finnhub_loader.py [NEW]
Replaces both yfinance and synthetic data. Contains 4 functions:
  • get_company_financials(ticker) — fetches last 8 quarters of real revenue, EBITDA, net income, EPS
  • get_company_profile(ticker) — name, sector, market cap, P/E ratio, revenue growth for Startup dashboard
  • get_peer_companies(ticker) — returns list of 5 competitor tickers
  • get_peers_financials(peers) — fetches financial metrics for each peer company
backend/data_sources/fred_loader.py [NEW]
Official macro data from Federal Reserve. Contains 2 functions:
  • get_macro_indicators() — fetches GDP growth, CPI inflation, Fed rate, unemployment, S&P 500, consumer confidence. Returns structured dict with value, previous, trend.
  • get_macro_summary_text() — returns single sentence like "GDP growth at 2.3%, CPI at 3.1%, Fed rate at 5.25%." — passed directly to the LLM News Agent prompt.
backend/data_sources/news_loader.py [NEW]
Replaces Alpha Vantage. 100 requests/day free:
  • get_company_news(company_name, ticker) — fetches last 7 days of real news headlines for a company. Returns top 5 titles.
  • get_market_headlines() — general US business news for macro context. Falls back to "Markets stable" if API unavailable.
backend/data_sources/csv_loader.py [NEW]
Parses user-uploaded CSV files. Required columns: date, revenue. Optional: ebitda, net_income, eps. Validates data, builds feature dict for XGBoost, returns structured result or clear error message.
backend/collect_training_data.py [NEW]
Run once to collect real training data. Fetches 25+ real company tickers from Finnhub (AAPL, MSFT, GOOGL, JPM, WMT etc). Takes ~5 minutes due to rate limits. Saves to out/real_training_data.csv. Then retrain XGBoost on this real data.
